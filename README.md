# Clementoni Studio

Portfólio de design gráfico de Fred Clementoni.

Site estático com 51 projetos, identidades visuais, embalagens, materiais editoriais, comunicação digital e visualização 3D.

## Publicação

Para publicar no GitHub Pages, escolha **Settings → Pages → Deploy from a branch → main → /(root)**.

Mantenha `index.html`, `assets` e `portfolio-assets` juntos.

## Direitos

Trabalhos apresentados por Fred Clementoni. Marcas, imagens e materiais de apoio pertencem aos respectivos titulares.
